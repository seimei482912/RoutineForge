# RoutineForge（たたき台）

Routinery（習慣化アプリ: ルーティンリマインダー、目標プランナー）を参考に、
PC-98系ピクセル・スコアパネル基調で作った自分専用ルーティン実行アプリの叩き台。
ビルド不要の素のHTML/CSS/JSのみ。PWA(manifest + service worker)対応。

## できること（MVP）

- ルーティン一覧（曜日別スケジュール、継続日数バッジ、週間達成状況）
- ルーティン実行タイマー（ステップごとの秒読み・自動で次のステップへ・一時停止/完了/スキップ）
- 完了サマリー（継続日数・合計日数・各ステップの実績）
- 達成演出（継続日数の全画面表示）
- ルーティンの追加・編集・削除（名前・アイコン・通知時刻・曜日・ステップ）
- データはブラウザのlocalStorageに保存（`routineforge_data_v1`キー）

## まだ入れていないもの（本家Routineryにあって今回省略した機能）

- 音声ガイド、BGM/ホワイトノイズ
- アプリが閉じている間のプッシュ通知（今回はローカル保存のみ。実現するには配信用サーバーが必要）
- チェックリストモード（タイマー無しの単純チェック）
- ウィジェット、スマートウォッチ対応
- 絵文字ピッカーUI（今はテキスト欄に直接絵文字を入力）

## ローカルで試す

```
cd RoutineForge
python -m http.server 8791
```

ブラウザで `http://127.0.0.1:8791/index.html` を開く。

## スマホにインストールして試す（PWAとして）

manifest / service worker はローカルの `http://127.0.0.1` や `http://localhost` でも動作するが、
スマホ実機の「ホーム画面に追加」を試すには同一Wi-Fi内でPCのIPをスマホから開くか、
実際にどこかにデプロイしてHTTPSで配信する必要がある（iOS Safariは同一LAN内のhttpアドレスでも
「ホーム画面に追加」自体は可能）。

本番配信する場合は、他のアプリと同様にRenderの静的サイト（Static Site）で無料公開できる。
このフォルダをそのままpublishすればよい（ビルドコマンド不要、Publish DirectoryをRoutineForge直下に）。

## 次に直すとよさそうな点（叩き台なので想定内）

- 曜日をまたぐ深夜ルーティンの扱い（今は日付で単純判定）
- 通知は「アプリを開いている間だけ」判定なので、本当にリマインダーとして使うなら
  Web Push（サーバー側の仕組み）を別途足す必要がある
- アイコンは絵文字テキスト直打ちなので、絵文字ピッカーを付けると入力しやすくなる
